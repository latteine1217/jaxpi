## 🎯 物理意义

### Kolmogorov Flow 特性

Kolmogorov Flow 是由周期性外力驱动的二维流动，在高雷诺数 (Re=10000) 下具有以下特征：

1. **湍流转捩**: 从层流到湍流的转变
2. **涡旋级联**: 能量从大尺度向小尺度传递
3. **强非线性**: 涡度场呈现复杂的时空结构

### 数据质量评估

- ✅ **分辨率充足**: 256×256 网格能够捕捉主要涡旋结构
- ✅ **时间采样合理**: 50 个时间步，步长 0.04
- ✅ **物理一致性**: 速度场统计特性符合理论预期
- ✅ **雷诺数准确**: ν = 0.0001 → Re = 10000

## 🔍 代码中的雷诺数使用

在 `examples/kolmogorov_flow/utils.py` 中：

```python
def get_dataset(Re=1e4, time_fraction=1.0):
    # 新格式（DNS/LES 兼容）
    data = np.load(
        "examples/kolmogorov_flow/data/kolmogorov_dns/kolmogorov_dns_10000.npy",
        allow_pickle=True,
    ).item()
    u_ref = data["u"]
    v_ref = data["v"]
    w_ref = data["omega"]
    t = np.array(data["time"]).flatten()
    config = data.get("config", {})
    nu = float(config.get("nu", 1.0 / Re))
    return u_ref, v_ref, w_ref, t, None, nu
```

**注意**: 代码会优先使用数据文件 `config["nu"]`，若缺失才回退到 `1/Re`。
